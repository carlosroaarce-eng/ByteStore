# ByteStore

Proyecto académico DSY1104 – frontend de tienda online con HTML, Bootstrap 5 y JavaScript.

## Funcionalidades
- Catálogo renderizado desde JavaScript
- Detalle de producto por URL `?id=`
- Carrito persistido en localStorage
- Validación en tiempo real de formularios
- Registro con regiones/comunas dinámicas
- Mantenedores de productos y usuarios
- Roles Administrador, Vendedor y Cliente
- Imágenes externas desde Pexels
- Diseño responsive mediante Bootstrap 5 + CSS personalizado mínimo
